# 周训练报告生成技能

## 适用场景

用户在对话中要求生成周报/本周训练总结/训练报告时使用。产出一个 Markdown 文件，
写入项目 `output/` 目录（这是 Agent 唯一可写的目录）。

## 执行步骤

1. **数据收集**：从对话上下文收集本周训练记录（运动类型、时长、心率、负荷）。
   若用户未提供某些数据，明确询问；若用户明确说"就用示例数据演示"，则使用
   以下虚构样例（不得使用任何真实个人信息）：
   - 周一 力量训练 60min 平均心率 125
   - 周三 跑步 40min 平均心率 150
   - 周五 力量训练 75min 平均心率 130
   - 周六 瑜伽 45min 平均心率 95
2. **工具计算**：对每次训练调用 `evaluate_training` 得到负荷；把每日负荷按
   下标 0=最近一天的顺序传入 `compute_fatigue` 得到疲劳指数；如用户关心体重，
   可再调用 `what_if_simulate`。
3. **模板渲染**：将计算结果填入下方模板，所有数值必须来自工具返回值，
   不得编造；每个结论后标注依据（工具名 + 输入）。
4. **确认后写入**：向用户展示报告全文，获得明确同意后调用
   `write_weekly_report(filename, content)` 写入；文件名格式
   `周训练报告_YYYY-MM-DD.md`。用户不同意则不写入，改为在对话中给出报告。

## 报告模板

```markdown
# 周训练报告（{起始日期} ~ {结束日期}）

## 一、本周训练概览

| 日期 | 运动类型 | 时长(min) | 平均心率 | 训练负荷 | 分档 |
| ---- | -------- | --------- | -------- | -------- | ---- |
| ...  | ...      | ...       | ...      | ...      | ... |

本周累计负荷：{sum}　|　训练次数：{count}

## 二、疲劳与恢复评估

- 疲劳指数：{index}（{level}），恢复系数 {factor}
- 依据：compute_fatigue，输入为本周每日负荷

## 三、下周建议

- 训练安排：基于疲劳等级给出 2–3 条建议
- 营养提示：简要宏量营养素建议

> 免责声明：以上为日常训练与营养参考，非医疗诊断；如有不适请就医。
```

## 边界

- 只使用对话中用户提供的或上述虚构样例数据，不猜测、不编造训练记录。
- 涉及伤病只建议休息与就医。
- 报告必须附带免责声明。
